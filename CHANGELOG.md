# Changelog

## 0.1.0 - first public test release
- Corsair iCUE LINK hub: lighting for all devices, fan and pump control with Quiet / Balanced / Extreme / Custom curves, liquid temperature, safety rules, multiple hubs.
- Lighting: 10 effects in sync (Temperature with your own colors, Static, Breathing, Color pulse, Rainbow wave, Spiral rainbow, Color cycle, Color wave, Visor, Off), direction, gamma-corrected fades, about 30 updates per second on Corsair devices; each effect shows only the settings it uses.
- Pump LCD: 13 animated themes picked from a list, each with its own colors, animation switches and Restore defaults; custom image / animated GIF; live preview; about 20 fps, paced by the screen; switching it off darkens the screen at once.
- MSI "761" boards (X870/X870E/B850/B840/Z890): built-in, mixed and exact-copy modes on JARGB1-3 + JAF; board allow-list.
- Corsair HXi/RMi PSU monitoring (read-only).
- Conflict detection (iCUE, Corsair Service, MSI Mystic Light, SignalRGB, OpenRGB, FanControl), diagnostics, logs, tray app, start with Windows.
