# Changelog

## 0.1.0 - first public test release
- Corsair iCUE LINK hub: lighting for all devices, fan and pump control with Quiet / Balanced / Extreme / Custom curves, liquid temperature, safety rules, multiple hubs.
- Pump LCD: Cyberpunk and Minimal templates, custom image / animated GIF, live preview, about 20 fps.
- MSI "761" boards (X870/X870E/B850/B840/Z890): built-in, mixed and exact-copy modes on JARGB1-3 + JAF; board allow-list.
- Corsair HXi/RMi PSU monitoring (read-only).
- Conflict detection (iCUE, Corsair Service, MSI Mystic Light, SignalRGB, OpenRGB, FanControl), diagnostics, logs, tray app, start with Windows.
